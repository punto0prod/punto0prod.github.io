Política de privacidad de PUNTO0 Publisher

Última actualización: 16 de octubre de 2026

Qué es

PUNTO0 Publisher es una herramienta interna de PUNTO 0 que se ejecuta en la computadora del equipo de PUNTO 0. Se usa solo para publicar videos propios de PUNTO 0 en las cuentas de PUNTO 0 en YouTube, Instagram, Facebook y TikTok.

Qué datos usa

  • YouTube (Google): con el permiso youtube.upload sube los videos que el equipo aprueba, y con youtube.readonly lee el nombre del canal y el estado de los videos subidos para comprobar que se publicaron bien.
  • Instagram, Facebook y TikTok: cuando se conecten, solo se usarán los permisos necesarios para publicar contenido propio y comprobar el resultado.

La herramienta no lee mensajes, contactos, comentarios ni datos de otras personas.

Dónde se guardan

Los permisos de acceso (tokens) y los registros de actividad se guardan solo en la computadora de PUNTO 0. No se envían a servidores propios ni a terceros, no se venden, no se usan para publicidad y no se usan para entrenar modelos de inteligencia artificial. Solo se transmiten a la plataforma correspondiente (por ejemplo, Google/YouTube) para realizar la publicación solicitada.

Datos de Google

El uso y la transferencia de la información recibida de las API de Google cumplen la Política de datos del usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

Cómo quitar el acceso

El acceso se puede revocar en cualquier momento desde el botón "Desconectar" de la herramienta o desde myaccount.google.com/permissions. Al desconectar, los permisos guardados se borran de la computadora.
